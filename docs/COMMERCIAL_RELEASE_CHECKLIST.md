# X Smart Evidence — Commercial Release Checklist

Before selling/deploying a build:

- [ ] Change version in `fxmanifest.lua`
- [ ] Confirm MR X / X Studio branding
- [ ] Confirm license terms for the specific customer
- [ ] Configure ACE permissions
- [ ] Back up `data/storage.json`
- [ ] Test case creation
- [ ] Test evidence creation
- [ ] Test check-out / return
- [ ] Test release
- [ ] Test destruction permissions
- [ ] Test admin deletion permissions
- [ ] Test resource restart persistence
- [ ] Test OneSync
- [ ] Test alongside the customer's framework/MDT
- [ ] Test NUI focus and close behavior
- [ ] Remove any customer-specific development data before delivery

## Important

A production sale should include a written agreement defining whether the customer receives:

1. a server-use license,
2. editable source under license,
3. source ownership/assignment, or
4. an exclusive/custom version.

The included license is a commercial-use license, not an automatic transfer of copyright ownership.
